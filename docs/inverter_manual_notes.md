# Must PV18-3224 VPM II — выжимка из инструкции (BMS, порты, программы)

Источник: инструкция пользователя к PV18-3224 VPM II (украинская редакция), программы и порты.

## Порты (стр. 6, 14)

- №12 «Порт зв'язку RS-485, CAN» — RJ45, порт BMS. Распиновка: 1 RS485-B, 2 RS485-A, 3 GND, 4 GND, **5 CAN-L,
  6 CAN-H**, 7–8 не используются.
- №13 USB — к нему подключена приставка (CH340, Modbus RTU 19200, адрес 4).
- №15 сухой контакт (по программе 37 управляется по напряжению или SOC).
- «Для связи с умной батареей можно использовать **только CAN**» (CAN-L, CAN-H, GND). Обычный сетевой кабель напрямую
  в порт ПК не включать.

## Программы, связанные с батареей (стр. 17–20)

| № | Назначение | Значения |
|---|---|---|
| 01 | приоритет источника | SBU / SOL / UTI (по умолчанию UTI). SBU/SOL переходят на сеть и обратно по порогам 20/21 (напряжение) или 38/39 (SOC) |
| 14 | тип батареи | для BMS-связи нужен «LI» |
| 37 | метод управления BMS | `VOL` (по умолчанию) — по напряжению; `SOC` — по проценту от BMS |
| 38 | SOC прекращения разряда (при наличии SOC) | 5–95 %, по умолчанию 20 % |
| 39 | SOC прекращения заряда (при наличии SOC) | 10–100 %, по умолчанию 95 % |
| 40 | связь с BMS | `IdP` (по умолчанию): при обрыве связи продолжает заряд/разряд; `Uni`: при обрыве останавливает |
| 41 | протокол литиевой батареи | 0–31, после смены перезапуск инвертора; список номеров в инструкции не приведён |

## Коды (стр. 20–21)

Ошибки 01–58 (совпадают с битами 25261/25262), предупреждения 61–77 (биты 25265): 61/62 вентиляторы, 63 перезаряд,
64 разряд, 67 перегрузка, 70 снижение мощности, 72–76 солнечный контроллер, 77 ошибка параметров.

## Вывод для моста BMS → инвертор

- Подать SOC от JK в инвертор можно только по CAN (порт №12), т.е. нужен USB-CAN адаптер на приставке и эмуляция
  протокола, номер которого выбирается программой 41.
- Обрыв связи при `40 = IdP` безопасен: инвертор продолжит работать как без BMS.
- По Modbus (USB) инвертор SOC не принимает; через Modbus можно только менять уставки (вариант Б).
