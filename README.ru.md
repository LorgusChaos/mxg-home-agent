# mxg-home-agent

Мониторинг и управление **инвертором серии Must PV1800** и литиевой батареей с **JK BMS** с помощью старой
Android ТВ-приставки. Сделано как монитор резервного питания (ИБП) для дома с частыми отключениями света; солнечные
панели не обязательны.

[English](README.md) · Установка: [INSTALL.md](INSTALL.md) · Использование: [USAGE.md](USAGE.md) ·
Технические решения: [docs/DECISIONS.md](docs/DECISIONS.md)

```
Инвертор ──USB (CH340, Modbus RTU)──┐
                                    ├── приставка: агент mxg (Go) ──Wi-Fi──► Telegram-бот (уведомления, /status)
JK BMS ────Bluetooth LE─────────────┘   (Android-мост)            └──ADB──► просмотрщик на ПК
```

## Возможности

- **Агент на приставке** (один статический бинарник Go, от root, автозапуск, приставку никогда не перезагружает):
  - опрос инвертора раз в 10 с по **Modbus RTU** через **собственный драйвер CH340** в пространстве пользователя
    (usbfs; модуля `ch341` в ядре приставки нет);
  - **JK BMS по Bluetooth LE** через маленькое Android-приложение-мост: настоящий SOC, ток, напряжение каждой ячейки,
    температуры, аварии, состояние ключей;
  - запись всех данных в суточные CSV и собственный журнал событий;
  - **Telegram-бот**: только события (свет пропал/вернулся с длительностью, каждые 10 % заряда, ошибки и
    предупреждения инвертора, аварии BMS, разбаланс ячеек, потеря связи) и команды `/status`, `/export`, `/mute`,
    `/adb_restart`;
  - самовосстановление: сторож зависшего adbd, удержание Wi-Fi без энергосбережения, часы по NTP (нет батарейки
    часов), **сброс питания USB-порта при зависании CH340** после переключения сети.
- **Просмотрщик на ПК** (`mxgview`, Windows): забирает данные с приставки по ADB и показывает локальную страницу:
  графики (батарея, ячейки, мощности, сеть, температуры, полосы отключений), таблицы, сводку по дням, журнал событий,
  **редактор настроек инвертора** (белый список, проверка пределов, обратное чтение, уведомление) и **экспорт для
  ИИ-анализа** (компактный архив с документом-контекстом).

## Проверенное железо

| Часть | Модель | Примечание |
|---|---|---|
| Приставка | Mini MX-G, Amlogic S905, Android 5.1.1, ядро 3.14 (64 бит), userland 32 бит | root через SuperSU 2.x (автозапуск `su.d`), ADB по сети |
| Инвертор | Must PV18-3224 VPM II (карта PV1800) | USB = CH340 `1a86:7523`, Modbus RTU 19200 8N1, адрес 4 |
| BMS | JK-B2A8S20P, hw 19H, sw 19.27, 8S LiFePO4 | BLE-протокол JK02_32S |

Другие приставки с root, инверторы Must семейства PV1800 и JK BMS с протоколом JK02 должны подойти с небольшими
изменениями — см. раздел «Адаптация» в [INSTALL.md](INSTALL.md).

## Структура

| Путь | Что там |
|---|---|
| `agent/cmd/mxg` | агент |
| `agent/cmd/mxgview` | просмотрщик (встроенная веб-страница) |
| `agent/cmd/mustprobe` | зонд инвертора: поиск протокола, чтение Modbus, развёртка регистров |
| `agent/internal/` | `usbfs`, `ch340` (драйвер), `proto` (Modbus RTU), `must` (регистры, ошибки, белый список настроек), `jkbms` (кадры BMS), `rules` (уведомления, с тестами), `store`, `tg` (Telegram), `sys` (Android), `soc` |
| `agent/deploy/` | скрипты на приставке: супервизор, запуск/остановка, обновление на месте, автозапуск `su.d` |
| `bmsbridge/` | Android-мост BLE (Java, сборка без Gradle) |
| `scripts/` | сборка, развёртывание, установка токена бота, сторож adbd |
| `docs/` | карта Modbus, выжимка из инструкции инвертора, технические решения, контекст для ИИ-анализа |

## Безопасность

В инвертор агент пишет **только** настройки из явного белого списка с осторожными пределами (например, напряжения
батареи ≤ 29,2 В для 8S LiFePO4), проверяет запись обратным чтением и сообщает о каждом изменении. Калибровка, сброс
счётчиков и отдача в сеть недоступны. Приставку агент не перезагружает — только перезапускает сбойные службы.

## Состояние

Работает в повседневном режиме. В планах — передача данных BMS в инвертор по CAN (эмуляция протокола Pylontech через
адаптер USB-CAN).
