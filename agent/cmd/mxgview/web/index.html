Экспорт для ИИ за выбранный период, шаг: контекст проекта + сводка + события + агрегаты + настройки, для загрузки в чат

Энергия за день считается по счётчикам инвертора (разница первого и последнего значения дня). Отключение — сетевое напряжение ниже 150 В.

Изменение уходит на приставку, агент проверяет его по своему списку и пределам, записывает в инвертор и читает обратно. О каждом изменении приходит сообщение в Telegram. Связь с приставкой медленная — ответ может занять до минуты.
